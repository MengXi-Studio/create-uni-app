# 🎉 create-uni-app v1.0.0 Released

> An interactive scaffolding CLI for uni-app + Vue3 + Vite

**Release date**: 2026-09-01 · **Version**: `1.0.0` · **License**: MIT

After focused polishing, `@meng-xi/create-uni-app` reaches its **first stable release**. It turns "setting up a uni-app project" from a pile of manual copy-and-trim into a clean command-line dialogue — answer a dozen questions and get a project skeleton that contains **only the capabilities you selected**.

---

## Why You Need It

Setting up a uni-app project by hand often carries three pains: picking through and trimming an official template, writing multi-platform scripts and dependencies one by one, and every teammate building their own setup. `create-uni-app` answers all three:

- **On-demand generation**: unselected languages, features, and platforms never appear — no extra files or deps
- **Everything in one go**: state, router, themes, request wrapper — injected as soon as you choose
- **Team unified**: custom template sources + `config set` let the whole team share one template set

## Core Capabilities

| Capability | Description |
| --- | --- |
| 🧩 Interactive creation | Project name → language → preprocessor → theme → state → router → platforms → features → package manager |
| 🌐 On-demand platforms | Covers all uni-app platforms; shortcuts for "All / Mini programs / Quick Apps" |
| 🃏 TS / JS | Mutually exclusive, each generating its own project config |
| 🎨 Built-in themes | Default Purple / Blue / Green / Orange, compatible with four preprocessors |
| 🗃️ State management | Pinia / Vuex (both with persistence) auto-injected into the main entry |
| 🧭 Router schemes | uni-router / generateRouter / generatePages / generateUni, mutually exclusive |
| 📦 Optional integrations | Request wrapper + auth, uni-ui (easycom) |
| 🛠️ Companion commands | `create` (add page), `info` (diagnose), `config` (persist template source) |

## Quick Start

```bash
npm i -g @meng-xi/create-uni-app
create-uni-app my-app

cd my-app
npm run dev:h5          # start H5
npm run dev:mp-weixin   # start WeChat mini program
```

You can also use it temporarily via `npx @meng-xi/create-uni-app my-app`.

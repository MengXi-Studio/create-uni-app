# 🎉 create-uni-app v1.0.0 正式发布

> 基于 uni-app + Vue3 + Vite 的交互式脚手架 CLI

**发布日期**：2026-09-01 · **版本**：`1.0.0` · **License**：MIT

经过集中打磨，`@meng-xi/create-uni-app` 迎来了**首个正式版本**。它把「搭建一个 uni-app 项目」从一堆手工拷贝与裁剪，变成一段清爽的命令行对话——回答十几个问题，就能拿到一个**只包含所选能力**的工程骨架。

---

## 为什么需要它

手动搭建 uni-app 项目往往伴随着三种痛苦：从官方模板里挑拣删改、逐个手写多端脚本与依赖、团队里每人各搭各的。`create-uni-app` 针对这些问题给出答案：

- **按需生成**：不勾选的语言、功能、平台，一律不出现，杜绝多余文件和依赖
- **一次到位**：状态管理、路由、主题、请求封装等，选完即自动注入
- **团队统一**：自定义模板源 + `config set`，让整个团队共享同一套模板

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 🧩 交互式创建 | 项目名 → 语言 → 预处理器 → 主题 → 状态 → 路由 → 平台 → 功能 → 包管理器 |
| 🌐 多平台按需 | 覆盖全部 uni-app 端，支持「全部 / 小程序(全部) / 快应用(全部)」快捷勾选 |
| 🃏 TS / JS | 互斥生成，`tsconfig.json` / `jsconfig.json` 各归其位 |
| 🎨 内置主题 | 默认紫 / 清新蓝 / 自然绿 / 温暖橙，兼容四种预处理器 |
| 🗃️ 状态管理 | Pinia / Vuex（均支持持久化）自动注入主入口 |
| 🧭 路由方案 | uni-router / generateRouter / generatePages / generateUni 互斥可选 |
| 📦 可选集成 | 请求封装 + 登录鉴权、uni-ui（easycom） |
| 🛠️ 配套命令 | `create` 建页、`info` 诊断、`config` 持久化模板源 |

## 快速上手

```bash
npm i -g @meng-xi/create-uni-app
create-uni-app my-app

cd my-app
npm run dev:h5          # 启动 H5
npm run dev:mp-weixin   # 启动微信小程序
```

同时支持 `npx @meng-xi/create-uni-app my-app` 免安装直接使用。

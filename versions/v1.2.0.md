# 🎉 create-uni-app v1.2.0 发布

> 交互体验优化 —— 内置主题可选、目标平台分组互斥、uni-ui 按预处理器联动

**发布日期**：2026-09-03 · **版本**：`1.2.0` · **License**：MIT

v1.2.0 聚焦**交互体验**：把"必选"里该是"可选"的项真正变成可选，并用互斥/联动规则消除重复与无效组合，让问答更贴合直觉，输出也更干净。

---

## 本轮更新

### 🧩 交互体验

- **内置主题改为可选功能**：不再作为必选步骤，并入「可选功能」多选，勾选后再挑色板（默认紫 / 清新蓝 / 自然绿 / 温暖橙）
- **目标平台分组互斥**：勾选「全部端 / 小程序(全部) / 快应用(全部)」时，其覆盖的具体平台自动禁用，避免重复勾选
- **uni-ui 按预处理器联动**：未选择 Sass/Scss 时自动禁用该选项并提示

### 🧰 修复

- 非 scss 方案（Less / Stylus / 原生 CSS）不再生成无用的 `uni.scss`

## 快速上手

```bash
npm i -g @meng-xi/create-uni-app
create-uni-app my-app

cd my-app
npm run dev:h5          # 启动 H5
npm run dev:mp-weixin   # 启动微信小程序
```

同时支持 `npx @meng-xi/create-uni-app my-app` 免安装直接使用。

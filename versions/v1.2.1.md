# 🎉 create-uni-app v1.2.1 发布

> Windows 兼容修复 —— 依赖自动安装与 H5 入口文件

**发布日期**：2026-09-20 · **版本**：`1.2.1` · **License**：MIT

v1.2.1 是**补丁版本**，修复 Windows 平台上实际使用中暴露的两个问题：依赖自动安装报 `spawnSync pnpm ENOENT`，以及 H5 运行报 `Failed to load url /main.ts`。

---

## 本轮更新

### 🐛 修复

- **Windows 下依赖自动安装失败**：pnpm / npm / yarn 在 Windows 上是 `.cmd` 脚本，CLI 直接 spawn 无法解析，报 `spawnSync pnpm ENOENT`；现改为经 shell 启动，自动安装恢复正常
- **H5 运行报 `Failed to load url /main.ts`**：生成项目 `index.html` 的入口路径修正为 `/src/main.ts`（JS 项目为 `/src/main.js`），与入口文件实际生成位置 `src/` 保持一致

## 升级建议

Windows 用户建议升级：

```bash
npm i -g @meng-xi/create-uni-app@latest
```

已用旧版创建的项目，手动把项目根目录 `index.html` 中的入口改为 `/src/main.ts` 即可，无需重新创建。

## 快速上手

```bash
npm i -g @meng-xi/create-uni-app
create-uni-app my-app

cd my-app
npm run dev:h5          # 启动 H5
npm run dev:mp-weixin   # 启动微信小程序
```

同时支持 `npx @meng-xi/create-uni-app my-app` 免安装直接使用。

# 🎉 create-uni-app v1.1.0 Released

> Structured generation — state management, the router instance and its guards are split into separate files for a cleaner project skeleton

**Release date**: 2026-09-01 · **Version**: `1.1.0` · **License**: MIT

v1.1.0 focuses on **structure quality and maintainability**: logic that used to be crammed into the main entry is split into its own files, so generated projects are cohesive in features and clean at the entry, with cleaner output and better version alignment.

---

## What's New

### 🗃️ State management: unified `stores/` + structured encapsulation

- Pinia / Vuex now share a single `stores/` directory (Vuex previously used `store`), with consistent entry references
- Pinia adds `stores/index` in which `createPiniaStore()` creates the instance and registers the persistence plugin; the entry keeps only `app.use(pinia)`

### 🧭 Router: instance and guards separated

- Generates a `src/router` directory: `index` creates the router instance (`createRouter` + plugins) and `guards` independently holds global `beforeEach` / `afterEach` guard examples
- The entry only does `import router from './router'` + `app.use(router)` instead of inlining the creation logic
- Pure uni-router still generates a handwritten `src/router.config`

### ⚙️ Build config adapts to the language

- TS projects generate `vite.config.ts`; JS projects keep `vite.config.js`

### 📦 Cleaner output

- `dependencies` / `devDependencies` in `package.json` are sorted alphabetically
- Default uni-app runtime version aligned to the official Vue3 channel (sync anytime via `npx @dcloudio/uvm@latest`)

### 🧰 Friendlier failure hints

- Dependency auto-install now surfaces the real exit code / spawn error plus a manual-retry hint for easier diagnosis
- Fixed a stray blank line in `stores/index` when Vuex persistence is disabled

## Quick Start

```bash
npm i -g @meng-xi/create-uni-app
create-uni-app my-app

cd my-app
npm run dev:h5          # start H5
npm run dev:mp-weixin   # start WeChat mini program
```

You can also use it temporarily via `npx @meng-xi/create-uni-app my-app`.
